# Xenith Studio

Make finished YouTube videos from one idea, on your own Mac, with your own Claude.

## Install (Mac, 2 steps, no commands to type)

**1. Get the Claude app.** Download it from https://claude.ai/download, install it and sign in with your Claude account
(Pro or Max plan). Then open **Claude Code** in the app.

**2. Let Claude set up Xenith.** Paste this into Claude Code and press Enter:

```
Set up Xenith Studio for me: https://github.com/StarVersePhoenix/xenith/blob/main/INSTALL.md
```

Claude downloads Xenith Studio, checks it, installs it, opens it and checks that it really runs. Then sign in to Xenith
with the email you joined with (you get a 6 digit code by email) and press **Install everything** in Setup.

**What you need:** a Mac with Apple silicon (M1 or newer), macOS 15 or newer, about 8 GB free space, and a Claude Pro or
Max plan. Windows is coming soon.

## Install by hand (if you prefer)
Download `Xenith-Studio-mac.dmg` from the newest release on the right of this page, open it and drag Xenith Studio into
Applications. The first time you open it, macOS asks you to confirm in System Settings > Privacy & Security > Open Anyway.

## Updates
Xenith updates itself: Settings > Updates. Your videos and settings stay in the Xenith folder in your home folder.

## Help
In Xenith, press **Health** in the left bar, then **Copy details for support**, and send it to us in the community.

## Add-ons
Some looks have optional add-on downloads. Xenith fetches them for members from inside the app.

Xenith Studio needs a membership: the app asks you to sign in when it opens.
